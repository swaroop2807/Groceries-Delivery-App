# Groceries Home Delivery App

A lightweight front-end app for browsing groceries, adding items to a cart, and placing a home delivery order.

## Features

- Product catalog with quick add buttons
- Real-time cart and total calculations
- Delivery checkout form with validation
- Order confirmation feedback

## Run locally

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
